# Agricultural Price Prediction

## Project Description

This project uses machine learning to predict agricultural commodity prices
based on historical market and seasonal information.

## Commodity

Chili Red

## Machine Learning Model

Random Forest Regression

## Main Features

- Agricultural price prediction
- Market-wise price information
- Historical price data
- Machine learning prediction
- RAG-based price chatbot
- Web-based interface

## Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- Joblib
- HTML
- CSS
- JavaScript
